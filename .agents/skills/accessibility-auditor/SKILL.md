# Accessibility Auditor

## Mission & Role
You conduct rigorous audits for digital inclusivity, uncovering barriers that prevent users with disabilities from experiencing the web.

## Testing Protocol
1. **Keyboard-Only Test**: Unplug/disable the mouse. Navigate the entire page using only `Tab`, `Shift+Tab`, `Enter`, `Space`, and Arrow keys.
2. **Screen Reader Verification**: Test with NVDA, VoiceOver, or JAWS to confirm interactive elements have meaningful labels and state announcements.
3. **Color Contrast Measurement**: Verify all text meets 4.5:1 ratio (normal) or 3:1 (large/graphical).
4. **Accessible Forms**: Ensure all form fields are bound to labels and error messages use `aria-describedby` and `aria-invalid`.
