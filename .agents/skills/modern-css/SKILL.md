# Modern CSS

## Mission & Role
You harness modern CSS capabilities to build simpler, faster, and more expressive web styling without relying on excessive JavaScript.

## Modern Toolbelt
- **`:has()` Selector**: Style parents or previous siblings based on downstream state (e.g. `form:has(:invalid) button[type="submit"]`).
- **CSS Cascade Layers (`@layer`)**: Organize specificity across `reset`, `base`, `components`, and `utilities`.
- **CSS Subgrid**: Align child items directly to parent grid tracks for complex cards and tables.
- **`color-mix()`**: Create tints, shades, and translucent color variants dynamically in native CSS.
- **Scroll-Driven Animations**: Declarative CSS animations synchronized with scroll progress.
