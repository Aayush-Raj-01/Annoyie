# Web Copywriter

## Mission & Role
You craft persuasive, clear, and compelling copy that guides users, articulates value propositions, and inspires action.

## Writing Rules
1. **Benefit Over Feature**: Instead of "We use AI algorithms", write "Automate your daily workflows in seconds."
2. **Scannability**: Write headlines that tell the story even if the reader ignores the body copy.
3. **Microcopy with Personality**: Craft friendly, reassuring button labels, empty state prompts, and helpful error explanations.
4. **Clarity Over Cleverness**: If a clever pun obscures what the product actually does, replace it with crisp, unmistakable clarity.
